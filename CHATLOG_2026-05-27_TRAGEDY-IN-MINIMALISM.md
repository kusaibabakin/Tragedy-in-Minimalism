## Предфинальная логика
- В player добавлен накопительный расчёт маршрута по выбору пользователя.
- Выборы теперь учитываются по трём линиям:
  - `dictator`
  - `citizen`
  - `neutral`
- Вход в предфинал больше не определяется только жёстко зашитым маршрутом:
  - если гражданская линия строго преобладает, используется `S_NEW_2`
  - если диктаторская линия преобладает или не уступает, используется `F0`
- Убрана старая variant-логика `F0`, завязанная на `previousId`.

## Тайм-аут выбора
- Изменена базовая механика choice-сцен:
  - окно выбора теперь появляется сразу при начале сцены
  - но переход по ветке по-прежнему происходит только после полного завершения видеофрагмента
- Исправлена ошибка, из-за которой окно выбора могло появляться дважды:
  - при старте сцены
  - и повторно за 3 секунды до конца
- Полностью убран старый механизм автослучайного выбора при бездействии пользователя.

## Retry-вставки при пропуске выбора
- Добавлен новый сценарий для тайм-аута выбора:
  - если пользователь не успевает сделать выбор, проигрывается случайная вставка
  - после вставки проект возвращает пользователя в ту же choice-сцену
  - выбор приходится сделать повторно
- Добавлены служебные сцены:
  - `Z_TIMEOUT_1 ... Z_TIMEOUT_7`
- Добавлен системный возврат:
  - `__RETRY_CHOICE__`
- В `story.json` добавлен список:
  - `choiceTimeoutInsertionIds`
- Локально в проект подключены видео вставок:
  - `z1.mp4 ... z7.mp4`
- Для публичной версии отмечено, что эти файлы нужно отдельно загружать в `R2`.
